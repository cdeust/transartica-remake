# Relevés documentaires

`villes.csv` contient les 44 lieux de la section Town list du [guide de Nikolaj W. Andersen](https://www.mogelpower.de/cheats/loesung.php?id=41910), consulté le 25 septembre 2026. Orthographes et coordonnées conservées. Ce sont des données rapportées par le guide, encore à comparer au jeu.

Cette liste ne couvre pas tous les lieux de quête et ne représente pas les voies ferrées. Elle sert de premier index pour les observations ; aucune connexion entre villes n'a été inventée.

## Parcours de vérification proposé

À partir du même guide : Rum/foreuse → Urga/clé → cimetière/code → Oslo/compteur Geiger, avec harpon pour le passage → sabotage par espion → équipement pour l'Himalaya → tunnel secret → Minotaurus/fin. Il s'agit d'un parcours rapporté, pas encore exécuté ni d'une liste exhaustive d'événements.

Un [témoignage de joueur et auteur de vidéos](https://www.dosgameclub.com/forums/topic/20-years-for-one-ending-screen/) mentionne une interaction précise à la centrale avant le combat final. Le guide résume cette partie : relever l'écran, la zone cliquable et l'effet exact avant de spécifier cette énigme. Cela justifie le recoupement avec le jeu et les vidéos.

Les contrôles de structure du CSV (colonnes, entiers, doublons) ne prouvent pas sa fidélité à l'original.
