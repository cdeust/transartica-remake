# Données de jeu

Ces fichiers sont les entrées runtime de l'édition anglaise Amiga500ECS
utilisées par le port C++. Ils sont versionnés et intégrés automatiquement
au jeu construit, conformément à la décision propriétaire du21octobre2026.

L'inventaire `../assets/interface/original-data-manifest.json` conserve
la provenance et les empreintes de l'édition décodée. Les chemins
`res://private-data/` qui subsistent dans les manifests sont des identifiants
historiques ; le runtime natif les résout dans ce dossier `data/`.

La licence MIT du nouveau code ne remplace pas l'attribution des contenus
historiques. Les illustrations et la musique créées pour le remake conservent
leurs notices dans `game/assets/`. La police Noto Sans conserve sa licence OFL.
