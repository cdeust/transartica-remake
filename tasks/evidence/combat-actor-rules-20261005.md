# Combat actor rules: 5 October 2026

The ECS listing in `reference-private/observations/combat-20260927/wdecor.txt` confirms four discrepancies in the actor port. This correction changes `tactical_actors.gd` and the mounted command routing in `tactical_scene.gd`.

- Melee snapshots both original strengths before either strike. Field offsets `0x2657/2668 → 2679/2843` and roof offsets `0x22e2/22f3 → 2308/23c7` permit retaliation even after the defender is eliminated. The port previously used reduced surviving strength and skipped the second draw after elimination. Both strikes now use the original counts, with the existing mammoth divisor retained. A surviving defender turns opposite the attacker and consumes its action for that pass (`0x2731/2373`, `0x2714/2376`). The roof sweep honors the same processed marker, including newly transferred groups, preventing a second independent action after retaliation.
- Roof movement cannot cross dynamite owned by the moving faction. Enemy groups reverse direction when blocked; player groups retain their direction (`0x1db4..1e25`). A friendly enemy group facing a different direction also causes reversal (`0x2295..22e1`). Opposing charges are still overwritten by movement.
- Enemy sabotage on the player roof rolls `rnd(100)` when crossing between wagons and `rnd(2000)` within a wagon (`0x1c73/1c8d`, `0x1d83`). Both use the strict aggressiveness comparison and a five-pass fuse. The crossing loop at `0x1d13..1d77` suppresses a charge if the immediately preceding cell has the same enemy direction type. A match in a later cell cannot undo the charge already written. Entry into a vital wagon places the charge ahead of the moving group. That write replaces an existing roof actor or charge and resets the fuse, as the source grid assignment does.
- Explicit mounted orders can dismount selected riders outside the mammoth's 2×2 footprint (`0x2e87..2f06`). Partial field selections become infantry; whole field selections change the mammoth direction (`0x32c1..3431`). Explicit edge orders board at the original mammoth column. A whole roof selection leaves one only when the group exceeds one (`0x30a3..30c2`). A solitary transfer removes the empty field actor before a paused save. Mounted arrows and mouse directions now pass the selected quantity, including the source maximum of 31; ordinary infantry retains its movement behavior and maximum of 30. Partial mounted field orders overwrite an occupied destination without invoking a casualty routine, matching the direct grid write. Explicit roof slot zero is accepted and survives paused JSON restore; the descending roof sweep leaves it untouched (`0x3051`, `0x1990`).

Validation: `test_tactical_actor_rules.gd` passes 122 checks. Replacing its actor preload with the preserved pre-change file yields 78 failed assertions and exit 1; the scene routing remains current in that baseline. Tests cover both factions, beast divisors, roof collisions, dynamite ownership and direction, strict sabotage thresholds and random draw bounds, eight rider directions, whole versus partial orders, solitary boarding and paused JSON restore. `test_tactical_combat.gd` also passes, including deterministic save continuation and 30/60/144 Hz equivalence. Source gate: zero errors and warnings. Craft gate: zero errors, one existing file-length advisory for `tactical_scene.gd`.

This is source and regression validation. The live earned battle remains paused; no native combat outcome is claimed here. Melee casualty mutations call the separate persistent survivor helper with both original counts; transfer, dismount and overwrite operations do not call casualty routines. Mounted deployment and survivor accounting are validated separately.

Known boundary: a partial mounted command into another mammoth writes one ECS grid cell, leaving the other footprint cells. The actor list cannot represent that fragmented footprint faithfully. This command is refused before mutation for all four mammoth cells, with a regression proving unchanged beasts and counters. Infantry destination overwrites are implemented and tested. This is an explicit unsupported fidelity boundary; no complete combat parity is claimed.
